== Abstract
Dieses Dokument beschreibt die Software- und Systemarchitektur des digitalen Zwillings für den Roboterarm MyPalletizer 260 M5 nach dem arc42-Standard. Das System ermöglicht die Entwicklung, den Test und die hybride Steuerung von Simulation (Unity) und physischer Roboterhardware über eine einheitliche, benutzerfreundliche Python-Schnittstelle. Es wurde im Rahmen des Moduls Applied Artificial Intelligence (APPLAI) an der Hochschule Luzern (HSLU) entwickelt.
